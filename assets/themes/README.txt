Coloca aquí tus imágenes PNG transparentes para las tarjetas de carpetas:

- makuin.png  -> Carpeta "Makuin" / "McQueen" / "Rayo" / "Cars"
- maikra.png  -> Carpeta "Maikra" / "Minecraft" / "Steve" / "Creeper"
- barbi.png   -> Carpeta "Barbi" / "Barbie" / "Rosa"
- default.png -> Cualquier otra carpeta

Si el archivo aún no existe, la app mostrará automáticamente una ilustración SVG temática de respaldo.
Para agregar nuevos modelos, edita `folderThemes.js`.
